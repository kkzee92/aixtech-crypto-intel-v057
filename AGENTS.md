# Agent rules for AIxTech crypto intel

- Research and paper-trading only. Never generate or suggest live order placement code.
- Do not hardcode or accept exchange API secrets, private keys, seeds, or withdrawal permissions.
- Prefer synthetic fixtures. Label data sources. No production personal data (PDPA-style).
- All changes must pass lint, tests, and secret scans.
- Disclose AI assistance in commits and PRs.
- Follow zero-trust: least privilege, attest sources, seal lineage.
